# Bento Grid Assets

Place your images in this folder (`src/assets/bento/`) and they will automatically load into their respective cards in the Bento Grid section.

### Supported File Formats
`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.avif`

---

### Card File Naming Guide

| Card | Description | Recommended Filename | Alternative Names |
|---|---|---|---|
| **Card 1** | Left Tall Card ($45M) | `tall.png` | `card1.png`, `bento1.png` |
| **Card 2a** | Middle-Left Top (15,400 Agents) | `card2a.png` | `agents.png`, `card2.png`, `bento2a.png` |
| **Card 2b** | Middle-Left Bottom (5x Speed) | `card2b.png` | `speed.png`, `bento2b.png` |
| **Card 3** | Middle-Right (Inference Speed / Rocket) | `card3.png` | `rocket.png`, `inference.png`, `bento3.png` |
| **Card 4** | Right (Cigna Quote / Testimonial) | `card4.png` | `quote.png`, `testimonial.png`, `cigna.png`, `card5.png` |

---

> **Note**: Vite will automatically detect any new images placed in this folder and hot-reload the page immediately without requiring a restart or manual import.
